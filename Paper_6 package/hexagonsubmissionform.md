## Title

The optimal log log q bound in the Pólya-Vinogradov inequality

## Abstract - copy the complete block

Using the $11/12$ consequence of OpenAI's formalised $7/8$ zero-free theorem for nonprincipal Dirichlet $L$-functions, we derive the bound $C\sqrt q\log\log q$ for every primitive Dirichlet character modulo $q\ge3$. The zero-free theorem is cited as an external input. We give the subsequent contour, prime-sum, major-arc and minor-arc arguments in detail and prove the required weak Montgomery--Vaughan exponential-sum estimate using Selberg's sieve. The same input yields $|L'/L(1,\chi)|\ll\log\log q$ and two-sided bounds for cyclotomic Euler--Kronecker constants. Explicit parameters and a general transfer argument show why any fixed uniform zero-free boundary below one suffices. No independent proof of the external zero-free theorem is claimed.
